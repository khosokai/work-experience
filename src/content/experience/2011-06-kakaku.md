## 不動産住宅情報サイト 開発・運用
- **期間**: 2013/04 〜 2015/01
- **業界**: 不動産
- **規模 / 役割**: 30名規模 / PG
- **担当工程**: 要件定義〜テスト
- **技術**: `PHP 5.4/5.5` `JavaScript` `MySQL 5.5` `Apache` `Ethna` `Symfony 2` `Redis` `jQuery` `Jenkins` `Subversion` `Redmine`

月間100万UU超、取り扱い物件数500万件の不動産住宅情報サイトの開発・運用。開発メンバーとして、サイト運用や新規コンテンツ開発を担当しました。

複雑な検索条件に対して素早く検索結果を返す必要があるため、DB チューニング、検索パラメータのハッシュ化、Redis による検索結果のキャッシュ化などを行いました。Jenkins によるリリース自動化にも取り組みました。

## 価格比較サイト 開発・運用
- **期間**: 2011/06 〜 2013/03
- **業界**: メディア
- **規模 / 役割**: 100名規模 / PG
- **担当工程**: 要件定義〜テスト
- **技術**: `VBScript` `C#.NET` `JavaScript` `SQL Server 2008/2012` `IIS 7.0` `Windows Server 2008 R2` `jQuery`

月間3000万UU（当時）の価格比較サイトの開発・運用。開発メンバーとして、プロバイダ、モバイルデータ通信、引越し、葬儀・葬式の各カテゴリを担当しました。
