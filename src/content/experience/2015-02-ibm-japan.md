## 車室内音声対話システム 提案・PoC制作
- **期間**: 2016/08 〜 2016/12
- **業界**: 製造業
- **担当工程**: 要件定義、PoC作成
- **技術**: `Node.js` `JavaScript` `Express` `AngularJS` `Cloudant` `Bluemix` `Watson Speech to Text` `Watson Text to Speech` `Watson Natural Language Classifier`

大手車載機メーカー向けの車室内音声対話システムの提案と PoC 制作。デリバリーメンバーとして、要件定義と、アイデアの実証を目的とした PoC 制作を行いました。

音声認識（Speech to Text）から内部処理を経て音声合成（Text to Speech）に至るまでの実測値測定、正確性の検証と改善提案を実施。ユーザーの行動分析から個人の性格や特性を判別し、最適な会話返答を返す検証も行いました。

## 自動運転支援システム 提案
- **期間**: 2016/03 〜 2016/07
- **業界**: 自動車
- **担当工程**: システム提案、要件定義
- **技術**: `Java` `JavaScript` `jQuery` `Cloudant` `Bluemix` `IoT for Automotive`

大手自動車メーカーの自動運転向けクラウド支援システムの提案。車載機のセンサーやレーダーだけでは認識できない道路状況や渋滞情報に、クラウドを活用するシステムです。

デリバリーメンバーとして、提案資料とサンプル画面の作成を担当。高速道路走行時のユースケースを洗い出してクラウドデータの活用方法を提案し、個車ごとの走行状態をモニタリングする画面サンプルを作成しました。

## テレマティクス用API 開発・運用
- **期間**: 2015/02 〜 2016/02
- **業界**: 自動車
- **規模 / 役割**: 30名規模 / PG
- **担当工程**: 要件定義〜テスト
- **技術**: `PHP 5.5/5.6` `Oracle 11g` `Apache` `Zend Framework 2` `AWS` `Subversion`

大手自動車メーカー向けテレマティクス用 API の開発。会員数200万人以上のカーナビシステムやスマートフォンアプリと連携する API です。

開発メンバーとして、API の要件定義からテストまでを担当。複数の他システムとの連携が必要なため、適切なトランザクション設計に注力しました。
